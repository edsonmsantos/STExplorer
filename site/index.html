  • Full ANSI + 256-color, xterm-compatible

Transfers

Drag. Drop.
Done.

Drop files from Windows Explorer straight into any remote folder. Or hit Ctrl+C on a file in Explorer, then Ctrl+V here — it just uploads.

  • Drag-and-drop from any file manager
  • Native clipboard integration (CF_HDROP)
  • Server-side copy for remote-to-remote moves
  • Live progress panel for every transfer
